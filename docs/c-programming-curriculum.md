+# C Programming Masterclass

## Publication status

The masterclass plan contains 12 modules and 100 lesson slots. The current
repository does not yet contain 100 reviewed C lessons or 120 verified C
examples, so this plan is not presented as a completed course and no empty
lessons are published.

## Module 1 authoring batch

The first review batch should be authored in this order:

1. What C is and where it is used
2. Source files, translation units, and the compilation pipeline
3. main, statements, blocks, and comments
4. C standards, hosted environments, and portability
5. Names, keywords, literals, and identifiers
6. Reading a small C program line by line
7. Compiler diagnostics and undefined behavior
8. Safe learning workflow and next steps

This batch requires at least ten distinct examples: a minimal program,
comments, multiple translation stages, a return value, a diagnostic example,
portable integer output, a constant, a block, a standard-version note, and a
safe error-aware program. They must be added through the CMS, reviewed, and
verified before publication.
