+# Lesson Authoring Guide

Every publishable lesson must include objectives, prerequisites, an
introduction, theory, syntax, worked examples, expected behavior, mistakes,
use cases, takeaways, glossary, knowledge checks, and related lessons.

Code examples must be complete, language-specific, and reviewed against the
documented compiler or runtime assumptions. Myanmar explanations are stored
separately from English content and require human review before publication.

An empty lesson, generic filler lesson, or unverified expected output cannot be
published. Admin publication is protected by the existing CMS permission and
publication validation workflow.
