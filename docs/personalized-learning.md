# Personalized learning

Phase 6 stores one student learning goal with career goal, current level, interests, weekly hours, pace, and display timezone. Recommendations are deterministic: published roadmap titles/categories matching the saved career goal rank first, followed by published options. Self-reported level is presented as context and never becomes verified mastery.

Roadmap progress is derived from linked evidence. Course resources require all published lessons completed; challenge resources require an accepted submission. Frontend progress values are never accepted as authoritative.
