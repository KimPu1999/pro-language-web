+# Code Example Standards

Examples are read-only in the lesson reader. Each example records its title,
language, source, position, and explanation. Examples should demonstrate one
concept at a time, progress from beginner to professional usage, and state
compiler or runtime assumptions where behavior is implementation-defined.

C examples must call out undefined behavior, ownership, bounds, integer
conversion, error handling, and portability risks when those concepts apply.
Untrusted student code is never executed by the API process; execution uses
the existing secure runner only from the practice interface.
