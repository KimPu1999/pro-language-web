# Organization roles

| Role | Scope |
| --- | --- |
| Owner | Organization membership, settings, teams and training administration |
| Admin | Organization administration except ownership transfer |
| Instructor | Training and assessment authoring within the organization |
| Team manager | Organization team and assigned team learning operations |
| Learner | Assigned learning and assessments |
| Viewer | Read-only permitted workspace views |

These roles never grant global `admin` or `super_admin` privileges.
