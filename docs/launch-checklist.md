# Launch checklist

- [ ] Production domains, HTTPS, trusted hosts, CORS, and secure cookies verified
- [ ] Managed PostgreSQL and Redis connectivity verified
- [ ] Migration release job and backup completed
- [ ] Worker health, email delivery, monitoring, and alerts verified
- [ ] Runner, AI, video, storage, and recordings configured or visibly disabled
- [ ] Staging smoke, security, accessibility, and load checks completed
- [ ] Restore test completed with recorded RPO/RTO evidence
- [ ] Critical security findings resolved
- [ ] Mobile and accessibility checks completed
- [ ] Production smoke tests completed
- [ ] Explicit Go/No-Go approval recorded
